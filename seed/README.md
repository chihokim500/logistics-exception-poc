# 시드 데이터 (가상)

`scripts/gen_seed.py`로 생성합니다 (난수 시드 고정, 다시 실행해도 같은 결과). 설계초안 6장 규칙을 따릅니다.
`scripts/verify_seed.py`는 설계초안 3·5장 규칙대로 `events.csv`를 재생하고 `expected_labels.csv`와 비교합니다. 구현할 시스템의 **기준 동작**으로 쓰면 됩니다.

```bash
python scripts/gen_seed.py
python scripts/verify_seed.py
```

모든 CSV는 UTF-8 BOM(엑셀 호환)입니다. 데모 기준일은 **2026-10-26**입니다.
